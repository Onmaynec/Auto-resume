# Changelog

## v3.8.0 — 2026-08-02

- added local Interview Prep Lab with separate versioned storage;
- Prep links to Tracker only by application ID, company and role;
- added deterministic RU/EN questions, editable answers, self-rating and STAR stories;
- readiness score 0–100 is explained by answer coverage, confidence, STAR evidence and planning;
- raw vacancy text, resume content, Kit and Audit report are excluded from Prep schema;
- added dedicated JSON/Markdown portability, offline support and privacy/browser coverage.

## v3.7.0 — 2026-08-02

- added local Application Tracker with statuses, follow-up workflow, filters and statistics;
- draft relation stores ID/name only;
- added dedicated JSON import/export and CSV formula-injection protection;
- Tracker is excluded from workspace backup, public share, API, Redis/KV and analytics.

## v3.6.0 — 2026-08-02

- added explainable local Resume Quality Audit across completeness, evidence, ATS readiness and readability;
- audit does not rewrite user text and remains outside workspace/share/API.

## v3.5.0 — 2026-08-02

- added browser-only Application Kit with cover letter, evidence prompts, gap plan and interview questions;
- raw vacancy text is not part of generated kit data.

## v3.4.0 — 2026-08-02

- added structured contribution/security workflow, private vulnerability reporting and documentation checks.

## v3.3.0 — 2026-08-02

- added versioned visual/ATS templates, safe presentation migrations and local custom logo.

## v3.2.0 — 2026-08-01

- added optional Redis/KV shared cache, distributed rate limiting, request coordination and session denylisting.

## v3.1.0 — 2026-08-01

- added controlled PWA updates and automated verified releases.

## v3.0.0 — 2026-08-01

- added GitHub OAuth with PKCE, encrypted HttpOnly sessions and authenticated-self analytics.

## v2.x

- introduced local DOCX/Markdown exports, RU/EN localization, PWA/drafts, profile comparison, vacancy analysis and public links.

## v1.x
