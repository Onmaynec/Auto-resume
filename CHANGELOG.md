# Changelog

## v3.8.0 — 2026-08-02

- added local Interview Prep Lab with separate versioned storage;
- Prep links to Tracker only by application ID, company and role;
- added deterministic RU/EN questions: intro, technical, project, behavioral, gap, candidate;
- question generation uses normalized skill/gap/project names, not raw vacancy text or resume content;
- added editable answers, completion state, self-rating 0–5 and STAR story bank;
- readiness score 0–100 is explained by answer coverage, confidence, STAR evidence and planning;
- added dedicated JSON import/export and local Markdown export;
- Prep data is excluded from workspace backup, public share, API, Redis/KV and analytics;
- public read-only resumes hide Prep panel;
- added offline app-shell assets and unit/privacy/Chromium/axe coverage.
