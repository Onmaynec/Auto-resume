# Changelog

## v2.2.0 — 2026-08-01

- приложение стало устанавливаемым PWA;
- добавлен offline app shell через Service Worker;
- API-ответы `/api/github` намеренно исключены из Service Worker cache;
- добавлены именованные локальные черновики резюме;
- добавлено автоматическое сохранение активного черновика;
- добавлены загрузка, переименование и удаление черновиков;
- добавлены экспорт и импорт локального рабочего пространства в JSON;
- добавлены индикаторы сети и свежести GitHub-данных;
- добавлена безопасная очистка API-кэша без удаления черновиков и настроек;
- добавлены unit и smoke-тесты PWA и резервных копий;
- версия пакета обновлена до 2.2.0.

## v2.1.0 — 2026-08-01

- добавлено сравнение двух GitHub-профилей по шести метрикам;
- добавлено отображение общих технологий;
- добавлена локальная история до восьми недавних профилей;
- добавлены светлая, тёмная и системная темы;
- добавлены skip-link, улучшенные focus-состояния и reduced-motion режим;
- добавлен GitHub Actions CI для pull request и main;
- добавлены unit-тесты настроек, истории профилей и сравнения;
- версия пакета обновлена до 2.1.0.

## v2.0.0 — 2026-08-01

- добавлен локальный анализ требований вакансии;
- добавлена оценка совпадения навыков и список недостающих технологий;
- добавлена автоматическая сортировка проектов по релевантности вакансии;
- добавлена реальная история commit contributions по языкам за 12 месяцев;
- добавлен stacked-график истории языков;
- добавлены публичные ссылки на готовое резюме через URL-фрагмент;
- добавлен read-only режим публичного резюме;
- добавлены тесты vacancy matching, share payload и monthly GraphQL query;
- версия пакета обновлена до 2.0.0.

## v1.1.0 — 2026-08-01

- график переименован в «Динамика активности»;
- добавлен выбор до пяти проектов;
- добавлена сортировка проектов перетаскиванием и стрелками;
- добавлено редактирование текста резюме прямо в макете;
- добавлен ATS-friendly шаблон с текстовым PDF через печать браузера;
- добавлен UTF-8 TXT-экспорт;
- добавлены автоматические тесты выбора проектов, текстового экспорта и обязательной разметки.

## v1.0.0

- генерация резюме по публичному GitHub-профилю;
- профиль, репозитории, языки и годовой календарь вкладов;
- визуальный PDF, графики и рекомендации по улучшению профиля.
