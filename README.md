# ✨ Auto Resume v1.1

> Веб-приложение, которое превращает публичный GitHub-профиль в редактируемое визуальное или ATS-friendly резюме разработчика.

## 🆕 Что нового в v1.1

- 📈 График получил корректное название **«Динамика активности»** и показывает вклад по месяцам.
- ✅ Можно выбрать до пяти проектов для резюме.
- ↕️ Выбранные проекты можно сортировать перетаскиванием или кнопками со стрелками.
- ✍️ Имя, заголовок, секция «О себе», проекты и навыки редактируются прямо в макете.
- 🤖 Добавлен простой ATS-friendly шаблон без аватара, диаграмм и декоративных блоков.
- 🖨️ ATS PDF создаётся через системную печать браузера, поэтому текст остаётся выделяемым и хорошо распознаётся рекрутинговыми системами.
- 📝 Добавлен прямой экспорт резюме в UTF-8 TXT.
- 🧪 Добавлены встроенные Node.js-тесты для выбора проектов и текстового экспорта.

## 🚀 Основные возможности

- 👤 Профиль: имя, аватар, био, локация и публичная статистика.
- 📦 Репозитории, языки, звёзды и форки.
- 🔥 Анимированный heatmap реальных вкладов за последние 12 месяцев.
- 📈 Динамика активности по месяцам.
- 🧠 Автоматический профессиональный заголовок и секция «О себе».
- 🎯 Процентное распределение языков.
- 💡 Рекомендации по улучшению GitHub-профиля.
- 📋 Копирование готового текста.
- 📄 Визуальный PDF через `html2canvas` + `jsPDF`.
- 🤖 ATS PDF с настоящим текстовым слоем через печать браузера.
- ⚡ Клиентский и serverless-кэш для экономии GitHub API.

## 🧩 Архитектура

```text
Браузер → /api/github?username=octocat → GitHub GraphQL API
```

Один GraphQL-запрос получает профиль, до 100 репозиториев, языки и календарь вкладов за год. Если serverless endpoint недоступен, интерфейс автоматически переключается на экономный REST-режим из двух запросов.

## ☁️ Развёртывание на Vercel

1. Импортируйте репозиторий в Vercel.
2. Откройте **Project Settings → Environment Variables**.
3. Добавьте:

```text
GITHUB_TOKEN=ваш_токен
```

4. Запустите новый deployment.

Токен используется только функцией `api/github.js` и никогда не отправляется в браузер.

## ▶️ Локальный запуск

Интерфейс с экономным REST fallback:

```bash
git clone https://github.com/Onmaynec/Auto-resume.git
cd Auto-resume
python -m http.server 8080
```

Полный режим с Vercel Functions:

```bash
npm install -g vercel
printf "GITHUB_TOKEN=your_token_here\n" > .env.local
vercel dev
```

## 📄 Экспорт

### Визуальный PDF

Создаётся через `html2canvas` и `jsPDF`. Подходит для отправки человеку и сохранения дизайна.

### ATS-friendly PDF

Выберите шаблон **ATS-friendly** и нажмите **«Сохранить ATS PDF»**. Откроется системный диалог печати; выберите **Save as PDF / Сохранить как PDF**. Документ формируется из HTML-текста, поэтому содержимое можно выделять, искать и копировать.

### TXT

Кнопка **«Скачать TXT»** сохраняет UTF-8 файл с текущими отредактированными данными и пользовательским порядком проектов.

## 🔒 Защита от лимитов

- один GraphQL-запрос вместо десятков REST-запросов;
- serverless-кэш на 15 минут;
- `localStorage`-кэш на 15 минут;
- ограничение запросов по IP;
- корректное отображение времени восстановления лимита;
- fallback из двух публичных REST-запросов.
