# ✨ Auto Resume v2.1

> GitHub-профиль превращается в адаптированное под вакансию, редактируемое и публичное резюме разработчика.

## 🆕 Что нового в v2.1

- ⚖️ **Сравнение профилей**: два GitHub-пользователя сопоставляются по подписчикам, репозиториям, звёздам, форкам, годовым вкладам и коммитам.
- 🕘 **Недавние профили**: последние открытые профили сохраняются локально и доступны одним кликом.
- 🌓 **Светлая, тёмная и системная тема** с сохранением выбора в браузере.
- ♿ **Доступность**: skip-link, улучшенные focus-состояния, подписи полей и поддержка `prefers-reduced-motion`.
- ✅ **GitHub Actions CI** запускает синтаксические проверки и тесты для каждого PR и изменения в `main`.
- 🔒 Настройки и история не отправляются на сервер и хранятся только в `localStorage`.

## 🚀 Возможности

- профиль: имя, аватар, био, локация, подписчики и количество репозиториев;
- репозитории: описание, topics, языки, звёзды, форки и ссылка;
- сравнение двух публичных GitHub-профилей;
- годовой contribution heatmap;
- график «Динамика активности» по месяцам;
- stacked-график истории языков;
- детерминированный локальный анализ вакансии;
- выбор до пяти проектов и сортировка drag-and-drop или стрелками;
- редактирование резюме прямо в макете;
- Visual PDF через `html2canvas` + `jsPDF`;
- ATS-friendly PDF через печать браузера;
- UTF-8 TXT-экспорт;
- публичная ссылка на готовое резюме;
- локальная история профилей и переключение темы.

## 🧩 Архитектура

```text
Браузер
  ├─ /api/github?username=octocat
  │    └─ GitHub GraphQL API
  ├─ локальный анализ вакансии и сравнение профилей
  ├─ localStorage: тема, недавние профили и API-кэш
  └─ #resume=<base64url-json> — публичное резюме без серверного хранения
```

Serverless endpoint одним GraphQL-запросом получает публичный профиль, до 100 оригинальных репозиториев, языки, topics, contribution calendar и помесячные commit contributions.

## ⚖️ Сравнение профилей

После загрузки основного пользователя укажите второй GitHub username. Приложение сравнит:

- подписчиков;
- количество публичных репозиториев;
- суммарные звёзды и форки;
- вклады и коммиты за 12 месяцев;
- общие технологии из топ-5 языков.

Второй профиль использует тот же безопасный API-прокси и кэш.

## 🌓 Темы и локальная история

Выбор темы и список до восьми недавних профилей хранятся в `localStorage`. Кнопка «Очистить» удаляет историю профилей. При системной теме интерфейс автоматически реагирует на настройки операционной системы.

## 🎯 Анализ вакансии

Текст вакансии анализируется в браузере. Требования сравниваются с языками, topics, названиями и описаниями репозиториев. Текст не отправляется во внешние AI API.

## 🔗 Публичные ссылки

Кнопка **«Скопировать публичную ссылку»** создаёт `#resume=<encoded-data>`. URL-фрагмент не отправляется серверу, но его содержимое видит каждый получатель ссылки.

## ☁️ Развёртывание на Vercel

1. Импортируйте репозиторий в Vercel.
2. Добавьте переменную окружения:

```text
GITHUB_TOKEN=ваш_токен
```

3. Выполните новый deployment.

## ▶️ Локальный запуск

```bash
git clone https://github.com/Onmaynec/Auto-resume.git
cd Auto-resume
python -m http.server 8080
```

Полный serverless-режим:

```bash
npm install -g vercel
printf "GITHUB_TOKEN=your_token_here\n" > .env.local
vercel dev
```

## ✅ Проверка

```bash
npm run verify
```

Команда выполняет синтаксическую проверку модулей, unit-тесты, smoke-тесты разметки и `git diff --check`. Те же проверки автоматически запускаются в GitHub Actions.

## 🔐 Приватность

- анализируются только публичные данные GitHub;
- GitHub token остаётся в serverless environment variable;
- вакансии, настройки и недавние профили обрабатываются локально;
- публичное резюме хранится в URL пользователя;
- PDF и TXT создаются в браузере.
