# ✨ Auto Resume

> Современное веб-приложение, которое превращает публичный GitHub-профиль в визуальное резюме разработчика.

## 🚀 Возможности

- 👤 Загружает имя, аватар, био, локацию и статистику профиля
- 📦 Показывает репозитории, языки, звёзды и форки
- 🔥 Строит анимированный 3D-heatmap активности
- 📈 Визуализирует рост активности по месяцам
- 🧠 Генерирует профессиональный заголовок и секцию «О себе»
- 🏆 Выбирает 5 лучших проектов по звёздам, форкам, свежести и качеству оформления
- 🎯 Показывает процентное распределение навыков на круговой диаграмме
- 💡 Даёт персональные рекомендации по улучшению GitHub-профиля
- 📋 Копирует резюме в буфер обмена
- 📄 Экспортирует резюме в PDF через `html2canvas` + `jsPDF`

## 🖼️ Интерфейс

Тёмная тема, glassmorphism-карточки, адаптивная сетка и аккуратные анимации. Приложение работает прямо в браузере и не требует регистрации.

## ▶️ Запуск

```bash
git clone https://github.com/Onmaynec/Auto-resume.git
cd Auto-resume
python -m http.server 8080
```

Откройте `http://localhost:8080` и введите GitHub username.

## ⚠️ Ограничения GitHub API

Приложение использует публичный GitHub REST API без авторизации. Для неавторизованных запросов действует ограничение частоты. GitHub Events API также возвращает только недавнюю публичную активность, поэтому число коммитов за год является оценкой на основе доступных событий.

Для production-версии рекомендуется добавить serverless-прокси и GitHub token на серверной стороне — не храните токен в клиентском JavaScript.

## 🧮 Как выбираются лучшие проекты

Проекты ранжируются по комбинированному баллу:

- звёзды × 5
- форки × 3
- свежесть обновлений
- наличие описания

## 🔐 Приватность

Используются только публично доступные данные. Приложение не хранит профили и не отправляет данные на сторонний backend.
