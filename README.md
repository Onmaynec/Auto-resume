# ✨ Auto Resume

> Современное веб-приложение, которое превращает публичный GitHub-профиль в визуальное резюме разработчика.

## 🚀 Возможности

- 👤 Загружает имя, аватар, био, локацию и статистику профиля
- 📦 Показывает репозитории, языки, звёзды и форки
- 🔥 Строит анимированный 3D-heatmap реальных вкладов за последние 12 месяцев
- 📈 Показывает накопленную динамику профессиональной активности по месяцам
- 🧠 Генерирует профессиональный заголовок и секцию «О себе»
- 🏆 Выбирает 5 лучших проектов по звёздам, форкам, свежести и качеству оформления
- 🎯 Показывает процентное распределение языков на круговой диаграмме
- 💡 Даёт персональные рекомендации по улучшению GitHub-профиля
- 📋 Копирует резюме в буфер обмена
- 📄 Экспортирует резюме в PDF через `html2canvas` + `jsPDF`
- ⚡ Кэширует ответы на клиенте и сервере, чтобы экономить лимит GitHub API
- 🛡️ Хранит GitHub token только в serverless-переменной окружения

## 🧩 Как устроено

Основной production-режим использует один serverless endpoint:

```text
Браузер → /api/github?username=octocat → GitHub GraphQL API
```

Один GraphQL-запрос получает:

- профиль пользователя;
- до 100 публичных оригинальных репозиториев;
- подробные языки каждого репозитория;
- календарь вкладов за 365 дней;
- количество публичных commit contributions;
- информацию об оставшемся лимите API.

Ответ кэшируется на 15 минут. Дополнительно действует простое ограничение частоты запросов по IP.

Если serverless endpoint недоступен, приложение автоматически переходит в экономный браузерный режим: профиль и репозитории загружаются всего двумя REST-запросами. В этом режиме точный годовой heatmap недоступен, но приложение продолжает работать и не расходует десятки запросов на языки.

## ☁️ Production-развёртывание на Vercel

1. Импортируйте репозиторий в Vercel.
2. Откройте **Project Settings → Environment Variables**.
3. Добавьте переменную:

```text
GITHUB_TOKEN=ваш_токен
```

4. Выполните новый deployment.

Токен нужен только serverless-функции `api/github.js`. Он никогда не встраивается в `app.js` и не отправляется пользователю.

Для проекта достаточно токена с минимальным доступом к публичным данным. Не добавляйте токен в репозиторий, HTML, клиентский JavaScript или `vercel.json`.

## ▶️ Локальный запуск интерфейса

```bash
git clone https://github.com/Onmaynec/Auto-resume.git
cd Auto-resume
python -m http.server 8080
```

Откройте `http://localhost:8080`. Без serverless-функции приложение автоматически включит экономный REST-режим.

## 🧪 Локальный запуск полного режима

Установите Vercel CLI и задайте переменную окружения в `.env.local`:

```bash
npm install -g vercel
printf "GITHUB_TOKEN=your_token_here\n" > .env.local
vercel dev
```

Откройте адрес, который покажет Vercel CLI. Файл `.env.local` не должен попадать в Git.

## 🔒 Защита от лимитов

Проект использует несколько уровней защиты:

- один GraphQL-запрос вместо 20+ REST-запросов;
- серверный кэш на 15 минут;
- браузерный `localStorage`-кэш на 15 минут;
- дедупликация данных по username;
- ограничение до 20 обращений к serverless endpoint за 10 минут с одного IP;
- корректное отображение времени восстановления лимита;
- экономный fallback всего на два публичных REST-запроса.

## 📊 Данные активности

В production-режиме календарь берётся из `contributionsCollection.contributionCalendar` GitHub GraphQL API. Он содержит ежедневные contribution counts за выбранный годовой период.

Отдельно отображается `totalCommitContributions` — количество публичных commit contributions за те же 12 месяцев. Heatmap показывает все публичные вклады, поэтому его итог может быть выше числа коммитов.

## 🧮 Как выбираются лучшие проекты

Проекты ранжируются по комбинированному баллу:

- звёзды × 5;
- форки × 3;
- свежесть последнего push;
- наличие описания.

Свежесть используется как показатель текущей активности проекта.

## 🔐 Приватность

- анализируются только публичные данные GitHub;
- токен хранится только в serverless environment variable;
- профили не записываются в базу данных;
- серверный и браузерный кэш автоматически устаревают;
- PDF создаётся непосредственно в браузере.
