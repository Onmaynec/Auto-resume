# ✨ Auto Resume v2.3

> GitHub-профиль превращается в адаптированное, редактируемое и публичное резюме на русском или английском языке.

## 🆕 Что нового

- 🌐 **RU/EN без перезагрузки**: интерфейс, статусы, ошибки, графики и конструктор переключаются мгновенно.
- 📄 **Локализованный экспорт**: секции ATS, TXT и PDF соответствуют выбранному языку.
- 💾 **Язык сохраняется** в настройках, локальном черновике и JSON backup.
- 🔗 **Публичная ссылка хранит локаль**; старые ссылки версии 2 открываются с русским fallback.
- 🧩 Все строки находятся в `js/i18n.mjs`, поэтому новую локаль можно добавить без копирования HTML.

## 🚀 Возможности

- анализ публичного GitHub-профиля и репозиториев;
- contribution heatmap и помесячная история языков;
- локальный анализ вакансии;
- сравнение двух профилей;
- выбор и сортировка проектов;
- Visual и ATS-шаблоны;
- экспорт PDF и TXT;
- публичные ссылки;
- PWA и offline app shell;
- локальные черновики, автосохранение и JSON backup;
- светлая, тёмная и системная темы;
- русский и английский интерфейс.

## 🌐 Архитектура локализации

```text
index.html
  └─ data-i18n / data-i18n-placeholder / data-i18n-aria-label

js/i18n.mjs
  ├─ ru dictionary
  ├─ en dictionary
  ├─ t(key, variables, locale)
  ├─ setLocale(locale)
  └─ applyTranslations(document)
```

Динамические модули используют те же ключи через `t()`. Метрики сравнения хранят locale-independent ключи, поэтому бизнес-логика не зависит от языка.

### Добавление новой локали

1. Добавьте код языка в `SUPPORTED_LOCALES`.
2. Создайте словарь с тем же набором ключей.
3. Добавьте option в `#localeSelect`.
4. Запустите `npm run verify` — тест проверит отсутствие пропущенных ключей.

## 🔗 Публичные ссылки

Payload версии 3 содержит поле `locale`. Декодер сохраняет совместимость с payload версии 2 и назначает ему русский fallback.

## 💾 Черновики и backup

Каждый черновик хранит собственную локаль. При открытии черновика интерфейс переключается на его язык. JSON backup переносит тему, язык, историю профилей и все черновики.

## ☁️ Развёртывание

Для полной GitHub GraphQL-аналитики добавьте в Vercel:

```text
GITHUB_TOKEN=ваш_токен
```

Токен используется только serverless-функцией `api/github.js`.

## ▶️ Локальный запуск

```bash
git clone https://github.com/Onmaynec/Auto-resume.git
cd Auto-resume
python -m http.server 8080
```

## ✅ Проверка

```bash
npm run verify
```

Проверяются JavaScript-модули, unit-тесты, RU/EN словари, локализованный ATS-экспорт, PWA shell, share payload и `git diff --check`.

## 🔐 Приватность

- анализируются только публичные данные GitHub;
- текст вакансии обрабатывается локально;
- настройки, язык и черновики находятся в браузере;
- `/api/*` не кэшируется Service Worker;
- публичное резюме хранится в URL-фрагменте пользователя.
